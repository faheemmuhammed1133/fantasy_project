# Dream11 Clone

A lightweight fantasy sports platform inspired by Dream11. This project features user registration, team management, contests, and real-time score updates.

---

## Features

- **User Authentication:** Secure registration and login.
- **Team Management:** Create and manage your fantasy team.
- **Contests:** Join public contests or create private ones.
- **Payment Integration:** Seamless transactions for contest entries.

---

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js & Express
- **Database:** MongoDB
---

## Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/yourusername/dream11-clone.git
   cd dream11-clone
   ```

2. **Install Dependencies:**
   ```bash
   cd frontend / backend  && npm install && cd ..
   ```

3. **Start the Application:**
   ```bash
   npm run dev
   ```
